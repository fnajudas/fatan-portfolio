Story

I began my career as a Backend Engineer, building and scaling production-ready systems using Golang and modern architecture patterns. Over the years, I took on hands-on data work as well — ETL, orchestration, and analytics-ready datasets across the full data lifecycle. Recently, I've been working on Learning Management Systems (LMS) with AI integration, real-time communication platforms, and multi-database architectures. I also share my knowledge through mentoring and training programs, helping developers grow their skills in backend engineering, system design, and best practices. Today, I focus on creating reliable backend services, scalable data pipelines, and developer tooling that empower teams to ship faster, make informed decisions, and operate with confidence.

What I do

  • Architect and develop backend services using Golang with clean, maintainable design patterns including Layered Architecture, Builder pattern, and modular systems.
  • Build real-time communication systems using LiveKit, WebSocket, and SSE for low-latency, high-concurrency applications.
  • Design and implement AI-integrated systems for automated content generation, question generation, and personalized learning paths.
  • Optimize multi-database infrastructures (PostgreSQL, MongoDB, Redis, Elasticsearch) and craft efficient queries for complex operations.
  • Build and orchestrate end-to-end data pipelines using Airflow, BigQuery, dbt, and cloud storage.
  • Develop code generation tools and automation to reduce boilerplate and accelerate development.
  • Mentor developers and deliver training programs on backend architecture, system design, and industry best practices.
  • Collaborate across engineering, product, and data teams to deliver high-impact features.

How I work

I work by combining clarity, structure, and collaboration—refining requirements, designing system architectures, validating solutions with QA, and documenting clear processes. I prioritize clean abstractions, reliable delivery, and continuous improvement to ensure every system becomes more stable and predictable over time. I practice TDD, comprehensive testing, code linting, and thorough documentation to reduce production bugs and improve code quality. When mentoring, I focus on hands-on learning, personalized guidance, and real-world system design to help developers become industry-ready engineers.
